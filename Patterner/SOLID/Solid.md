# Принципы SOLID
- Один класс отвечает только за свою задачу  
-- класс делает только что-то одно
- Принцип открытости/закрытости
-- Программы/сущности открыты для изменения, но закрыты для модификации
- Принцип разделения интерфейсов
-- много специализированных интерфейсов лучше, чем один универсальный
- Принцип подстановки 
- Принцип инверсии зависимостей
-- Зависимости должны строиться на абстракциях, а не на реализациях
